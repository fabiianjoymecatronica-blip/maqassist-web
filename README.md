# AWO Group — sitio web corporativo

Primera versión del sitio corporativo de AWO Group, preparada para desplegarse como aplicación Node.js en Hostinger.

## Publicación en Hostinger

1. En **Sube los archivos**, carga el archivo ZIP completo.
2. Hostinger detectará `package.json`.
3. El comando de inicio debe ser `npm start`.
4. No se requieren variables de entorno.
5. Una vez publicado, prueba el menú, todos los botones de WhatsApp y el contacto por WhatsApp.

## Contenido incluido

- Página de inicio responsive.
- Servicios de mantenimiento, reparación, repuestos, maquinaria y automatización.
- Sectores alimentario, farmacéutico, cárnico y manufactura.
- Planes AWO Group Care.
- Botones de cotización por WhatsApp.
- Datos de contacto y cobertura nacional.
